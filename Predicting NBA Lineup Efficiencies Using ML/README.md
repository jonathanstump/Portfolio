# Predicting NBA Lineup Efficiency Using Player Archetypes

In this paper we present our methodology for defining basketball player archetypes in the NBA 
from statistical analysis techniques: Principal Component Analysis and K-Means Clustering. 
We then use these labels to predict efficiency based on lineups and combinations of players 
in the 2024-2025 and 2025-2026 NBA seasons.
